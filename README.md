# meArm 机械臂 - 算法考核项目

机器人学院十二期二面考核 - 算法方向

## 硬件平台
- Arduino Uno
- meArm 机械臂（4路舵机）
- 双摇杆模块

## 引脚定义

### 舵机
| 舵机 | 引脚 |
|------|------|
| 底座 (base) | 2 |
| 大臂 (rArm) | 3 |
| 小臂 (fArm) | 4 |
| 夹爪 (claw) | 5 |

### 摇杆
| 摇杆 | 引脚 | 控制功能 |
|------|------|----------|
| 左摇杆X | A0 | 底座旋转 |
| 左摇杆Y | A1 | 大臂抬落 |
| 右摇杆X | A2 | 小臂伸缩 |
| 右摇杆Y | A3 | 夹爪开合 |

## 串口指令

| 指令 | 功能 | 示例 |
|------|------|------|
| `b` + 数字 | 底座转到指定角度 | `b90` |
| `r` + 数字 | 大臂转到指定角度 | `r45` |
| `f` + 数字 | 小臂转到指定角度 | `f120` |
| `c` + 数字 | 夹爪转到指定角度 | `c30` |
| `o` | 查看所有舵机当前角度 | `o` |
| `h` | 加速（减小DSD） | `h` |
| `l` | 减速（增大DSD） | `l` |
